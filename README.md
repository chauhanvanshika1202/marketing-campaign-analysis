# Marketing Campaign Response & Customer Segmentation Analysis

## Overview
An end-to-end data analysis project using Python, SQL, and Streamlit to analyze customer purchasing behavior and optimize marketing campaign performance for 2,232 customer records.

## Tech Stack
* **Python:** Pandas, Plotly (Data cleaning, feature engineering, and visualization)
* **SQL:** SQLite, CTEs, Window Functions (`NTILE`, partitioning) for behavioral metrics
* **Web App:** Streamlit (Interactive dashboard for exploring metrics and response simulator)

## Key Findings
* Identified a high-value segment (high income, zero children, recent purchasers) with a **45.3% response rate**, significantly above the **14.9% average**.
